# Sales Data Analysis using SQL & Power BI

## Project Overview
This project focuses on analyzing sales data using SQL Server and creating an interactive dashboard in Power BI. The goal is to identify sales trends, understand customer purchasing behavior, and evaluate product and category performance.

## Tools & Technologies
- Microsoft SQL Server
- SQL
- Power BI
- DAX

## Database Structure
The project contains two tables:

- **Sales**: SaleID, CustomerID, ProductName, Category, Quantity, Price, SaleDate
- **Customers**: CustomerID, CustomerName, City

## SQL Analysis
The following analyses were performed:

- Total revenue calculation
- Category-wise revenue analysis
- Product-wise sales and revenue
- Customer spending analysis
- Monthly sales trends
- Top customers ranking
- High-value sales identification
- Revenue percentage by category
- Cumulative revenue analysis

## Power BI Dashboard
An interactive dashboard was created with:

- Total Revenue KPI Card
